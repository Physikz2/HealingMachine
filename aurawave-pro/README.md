**AuraWave Pro™** is a production-grade, highly polished frontend web application that simulates an advanced Quantum Cellular Bio-Resonance and Regeneration healing machine. Blending cutting-edge medical-grade hardware aesthetics with dynamic canvas telemetry, it provides users with an immersive bio-harmonic frequency tuning and regeneration interface.

## 🚀 Key Features & Architecture

* **Futuristic UI/UX Design:** Built with a deep dark-mode obsidian and slate palette (`#0b0f19`), accented with glowing neon cyan (`#06b6d4`) and emerald (`#10b981`) glassmorphism containers.
* **Cinematic 10-Second Hero & Product Video Component:** An interactive preview engine featuring custom CSS keyframe animations and HTML5 canvas logic simulating a looping promotional commercial of the internal quantum plasma spark gap fields.
* **Interactive Spark Gap & Component Explorer:** Direct translation of technical blueprints (inspired by *Building the renewed Spark Gap.pdf*) into an interactive node explorer detailing internal subsystems.
* **Live Bio-Resonance Telemetry:** Real-time data readouts tracking resonance frequency, bio-field coherence, plasma chamber temperature, and session progress timers.

## 🛠️ Tech Stack
* **Frontend Core:** TypeScript, React / Modern Component Architecture
* **Styling:** Tailwind CSS with custom glassmorphism and glow utilities
* **Build Tool:** Vite (`vite.config.ts`)
* **Deployment:** Netlify Static Hosting
